# Upx100.ru — Платформа для поиска и записи на услуги

Веб-платформа, где предприниматели (исполнители услуг) могут размещать услуги с окнами времени для записи, а клиенты — искать услуги и отправлять заявки на запись.

## 🔧 Технологический стек

### Бэкенд
- **Python 3.11+**
- **Django 5.0+**
- **Django REST Framework** (для будущего API)

### База данных
- **SQLite** (для разработки)
- **PostgreSQL** (рекомендуется для продакшена)

### Поиск
- **FAISS** (векторный поиск — в разработке)
- **PostgreSQL trigram + координаты** (для полнотекстового и геопоиска)

### Очереди и кэш
- **Redis** (кэш, очереди задач)
- **Celery** (фоновые задачи, уведомления)

### Контейнеризация и деплой
- **Docker & Docker Compose**
- **Nginx** (прокси + статика)
- **Gunicorn** (WSGI сервер)

### Фронтенд
- **Django Templates**
- **HTML5 + CSS3 + JavaScript (Fetch API)**

## 🚀 Быстрый старт

### Требования
- Python 3.11 или выше
- pip (менеджер пакетов Python)
- SQLite (встроен в Python)

### Установка зависимостей

```bash
# Создайте виртуальное окружение
python -m venv venv

# Активируйте виртуальное окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### Настройка базы данных

```bash
# Примените миграции
python manage.py migrate

# Создайте суперпользователя (администратора)
python manage.py createsuperuser
```

### Запуск сервера разработки

```bash
# Запустите сервер
python manage.py runserver

# Откройте браузер по адресу: http://127.0.0.1:8000/
```

## 👥 Роли пользователей

### Администратор
- Доступ к админ-панели Django (`/admin/`)
- Управление глобальными категориями и подкатегориями
- Управление пользователями (блокировка, смена ролей)

### Предприниматель (Бизнес)
- Регистрация и заполнение профиля компании
- Создание профилей сотрудников
- Создание услуг с временными слотами
- Просмотр заявок на запись
- Оплата публикации услуг (100 руб./мес.)

### Клиент
- Поиск услуг (текстовый, по категории, локации)
- Просмотр страниц услуг со свободными слотами
- Отправка бесплатных заявок на запись

## ✨ Основные функции

### Для предпринимателей
- ✅ Регистрация и профиль компании
- ✅ Профили сотрудников
- ✅ Создание услуг с описанием, ценой и длительностью
- ✅ Генерация временных слотов для записи
- ⏳ Оплата услуг через эквайринг (в разработке)
- ⏳ Управление заявками на запись

### Для клиентов
- ✅ Поиск услуг с фильтрами
- ⏳ Векторный семантический поиск (FAISS — в разработке)
- ⏳ Поиск по локации (радиусный поиск)
- ✅ Форма записи на услугу (выбор слота, имя, email, примечание)
- ⏳ Уведомления о записи (email, ЛК)

### Администрирование
- ✅ Управление категориями и подкатегориями
- ✅ Управление пользователями
- ⏳ Статистика и аналитика (в планах)

## 🛠 Разработка

### Запуск с отладкой

```bash
# Установите зависимости для разработки
pip install -r requirements.txt

# Запустите сервер с отладочной панелью
python manage.py runserver
```

### Создание миграций

```bash
# После изменений в моделях создайте миграции
python manage.py makemigrations

# Примените миграции
python manage.py migrate
```

### Тестирование

```bash
# Запустите тесты
python manage.py test
```

### Сбор статики (для продакшена)

```bash
# Соберите все статические файлы
python manage.py collectstatic
```

## 🐳 Docker (опционально)

Для запуска в контейнерах (требуется установка Docker):

```bash
# Сборка и запуск
docker-compose up --build

# Остановка
docker-compose down
```

## 📝 Дальнейшие шаги

### В разработке
1. **Система оплаты** — интеграция с платёжным шлюзом
2. **Векторный поиск** — внедрение FAISS для семантического поиска
