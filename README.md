# Upx100.ru — Платформа для поиска и записи на услуги

Веб-платформа, где предприниматели (исполнители услуг) могут размещать услуги с окнами времени для записи, а клиенты — искать услуги и отправлять заявки на запись.

## 🔍 Векторный поиск

Платформа использует **FAISS** (Facebook AI Similarity Search) с нейросетевыми эмбеддингами от **Sentence Transformers** для семантического поиска услуг. Это позволяет находить услуги по смыслу, а не только по точному совпадению слов.

### Установка зависимостей для векторного поиска

```bash
pip install -r requirements.txt
```

В `requirements.txt` уже включены необходимые пакеты:
- `faiss-cpu==1.8.0` — библиотека для быстрого поиска похожих векторов
- `sentence-transformers==2.7.0` — генерация текстовых эмбеддингов
- `numpy==1.26.4` — совместимая версия NumPy

### Построение векторного индекса

Первый раз индекс нужно построить вручную:

```bash
python manage.py build_vector_index
```

Процесс:
1. Загружается модель `paraphrase-multilingual-MiniLM-L12-v2` (~470MB)
2. Для всех активных услуг генерируются векторные представления
3. Векторы сохраняются в базе данных и индексируются через FAISS
4. Индекс кэшируется в памяти для быстрого поиска

### Автоматическое обновление индекса

Для ежедневного обновления индекса в 3 часа утра настройте cron:

**Linux/Mac:**
```bash
crontab -e
# Добавьте строку:
0 3 * * * /путь/к/проекту/search/build_index_cron.sh
```

**Windows (Task Scheduler):**
1. Откройте "Планировщик заданий"
2. Создайте задачу на 3:00 ежедневно
3. Действие: `python manage.py build_vector_index`

### Как работает поиск

1. Пользователь вводит запрос (например, "мужская стрижка")
2. Запрос преобразуется в вектор через Sentence Transformer
3. FAISS находит ближайшие векторы услуг по косинусному сходству
4. Результаты возвращаются с учётом семантической близости

Это позволяет находить услуги даже при неточном формулировании запроса!

## 👥 Роли пользователей

### Администратор
- Доступ к админ-панели Django (`/admin/`)
- Управление глобальными категориями и подкатегориями
- Управление пользователями (блокировка, смена ролей)

### Предприниматель (Бизнес)
- Регистрация и заполнение профиля компании
- Создание профилей сотрудников
- Создание услуг с временными слотами
- Просмотр заявок на запись
- Оплата публикации услуг (100 руб./мес.)

### Клиент
- Поиск услуг (текстовый, по категории, локации)
- Просмотр страниц услуг со свободными слотами
- Отправка бесплатных заявок на запись
